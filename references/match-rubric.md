# Match rubric

Score 0-100. Show the breakdown, not just the total.

| Dimension | Weight | Full credit when |
|---|---|---|
| Must-have skills | 30 | Every "required" skill in the JD appears in the profile |
| Years of experience | 15 | Profile is within the stated band (over by <2 yrs is fine) |
| Seniority match | 15 | Title band matches; one level up is a stretch, two is out |
| Location / work mode | 15 | Location and on-site expectation both work for the user |
| Domain / industry | 10 | Prior work in the same domain |
| Tech stack overlap | 10 | Nice-to-haves in the JD are also in the profile |
| Company signals | 5 | Size, stage, reputation fit the user's stated preference |

Bands: 80+ apply, 60-79 apply if the shortlist is thin, <60 skip unless the user asks
(or `preferences.md` says "apply to every plausible match" - then the score is advice).

## Dealbreakers - reject at any score
- A country the user cannot legally work in, or sponsorship the employer rules out
- A clearance or citizenship requirement the user does not meet
- Unpaid, "equity only", or pay-to-apply
- On-site in a city the user ruled out
- Seniority two or more levels away from the target band
- A must-have skill that is on the user's boundary list
- Contract or duration terms the user excluded

## Always report
The single strongest reason to apply and the single most likely reason to be screened
out. The user decides: never quietly drop a borderline role.
