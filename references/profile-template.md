# Candidate profile (template)

Copy to `<workspace>/profile.md` and fill in during onboarding. This is the single
source of truth for every application. Facts only: if it is not here and not in the
resume, ask the user. This file holds personal data - it must never be stored inside the
skill folder, committed to a public repo, or pasted into third-party tools.
